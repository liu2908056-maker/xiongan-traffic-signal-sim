# 路口命名与几何说明

## 命名原则

`data/xiong_an_20/topology.json` 的 `labels` 是展示用名称。能从随附高德截图文件名或既有位置说明确认的路名保留为“道路/门牌附近”；无法确认的节点明确标为“容东片区某侧/某部”，没有把推测名称伪装成真实交叉口。

已确认的示例包括：

- J02：津海大街-奥威路，容和塔北侧（来自现有路口 2 位置说明）。
- J04：将台路 217 号附近。
- J07：中心大街 16 号附近。
- J08：雄州路 788 号附近。
- J10：保静公路 G336 附近。
- J13/J20：小康路 2 号附近。
- J17/J19：津保路 1 号附近。

## 几何原则

项目保留 4x5 的规则控制拓扑，但节点使用轻微不等距坐标，道路使用三点 CityFlow polyline（中点有小幅侧向偏移），因此可表现弯曲道路和不规则道路走向。`roadnet.json` 中的 `points` 是仿真几何，不是高德底图坐标。

## OSM/netedit 边界

本交付没有宣称已经导入 OSM 或完成 netedit 测绘，因为随附材料没有提供可核验的经纬度、道路中心线、车道数和真实信号连接。若要达到严格 OSM/netedit 级别，应取得合规 OSM/测绘数据，在 netedit 中导出真实 roadnet，再保留本项目的流量解析、算法适配和动态监控层。当前路网是基于随附高德截图和路名线索的可审计近似模型。

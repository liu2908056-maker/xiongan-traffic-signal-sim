# 常见错误与解决方案（Troubleshooting）

## 1. CityFlow 编译失败：pybind11 与 Python 3.11+ 不兼容

- **现象**：`pip install ./third_party/CityFlow` 报错，出现 pybind11 2.3.0 相关错误。
- **原因**：CityFlow 固定提交 `81ee0f4` 内置 pybind11 2.3.0，不兼容 Python 3.11+。
- **解决**：使用 Python 3.10 —— `danielda1/ugat` 镜像为 3.10.6；自包含基线镜像 `Dockerfile.cityflow_baseline` 基于 `python:3.10-slim`。

## 2. 拉取 `danielda1/ugat:latest` 失败或过慢

- **现象**：`docker pull` 超时 / 无外网。
- **原因**：镜像约 8.47GB，需稳定外网。
- **解决**：改用随包离线镜像 `docker load -i docker/xiong-an-cityflow-submission.tar`（仅基线场景）；或改用 `Dockerfile.cityflow_baseline` 自包含构建。

## 3. 内存不足 / 进程被 kill

- **现象**：7500 步运行时进程被杀。
- **解决**：降低 `--threads` 或 `--steps`；增加主机内存（建议 ≥8GB）。

## 4. `outputs/metrics.csv` 未生成

- **现象**：跑完后找不到结果文件。
- **原因**：`--out-dir` 未挂载到宿主机。
- **解决**：加 `-v "$PWD/outputs:/app/outputs"` 挂载。

## 5. `docker: command not found`

- **解决**：`curl -fsSL https://get.docker.com | sh`，重新登录使 `docker` 组生效。

## 6. 架构不匹配（Apple Silicon 上跑 x86_64 镜像）

- **现象**：`exec format error`。
- **解决**：在云主机（原生 amd64）上跑；本地 Mac 需开启 Rosetta 2 或用 `--platform linux/amd64`。

## 2. 复现步骤与命令

1. 上传 / 解压代码包：
   ```
   tar xzf 功能二-任务三.tar.gz && cd 功能二-任务三
   ```
2. 构建镜像（自包含基线，不依赖外部 UGAT 镜像）：
   ```
   docker build -f Dockerfile.cityflow_baseline -t xiong-an-20-platform:final .
   ```
3. 冒烟验证（100 步）：
   ```
   docker run --rm -v "$PWD/outputs:/app/outputs" xiong-an-20-platform:final --period morning --algorithm max_pressure --steps 100 --threads 1
   ```
4. 正式评测（7500 步）：
   ```
   docker run --rm -v "$PWD/outputs:/app/outputs" xiong-an-20-platform:final --period morning --algorithm max_pressure --steps 7500 --threads 4
   ```

# 性能对比表（模板）

> 数据待填。填表前提：所有算法在**同一场景、同一流量、同一随机种子**下运行，指标方可公平对比。
> 指标来源：`outputs/metrics.csv`（由 `src/run_cityflow.py` 输出）。生成方式：`python scripts/benchmark.py`。

## 指标定义

| 指标 | 字段 | 含义 | 方向 |
|---|---|---|---|
| 平均旅行时间 | `average_travel_time_s` | 车辆平均行程时间（秒） | 越低越好 |
| 平均延误 | `estimated_delay_s` | 相对自由流的额外延误（秒） | 越低越好 |
| 吞吐量 | `throughput_est` | 完成车辆 / 总需求 | 越高越好 |
| 最终排队 | `final_queue_proxy` | 仿真结束时刻排队代理值 | 越低越好 |
| 运行速度 | `steps_per_second` | 每秒仿真步数（性能） | 越高越好 |
| 单次时长 | `wall_seconds` | 单次运行墙钟时间 | — |

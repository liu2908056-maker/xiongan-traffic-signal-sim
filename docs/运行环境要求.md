# 运行环境要求

## 硬件

| 项 | 最低 | 建议 |
|---|---|---|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 20 GB | 40 GB+（`danielda1/ugat` 镜像约 8.47GB） |
| GPU | 不需要 | 可选（UGAT 训练可 CPU 降级） |

## 软件

| 项 | 版本 |
|---|---|
| 操作系统 | Linux x86_64（amd64），勿用 arm |
| Docker | 任意较新版本 |
| Python | 3.10（镜像内置；宿主机只需 Docker） |

## 依赖版本

`requirements.txt` 当前为下限约束（`>=`），提交前建议锁定精确版本：在验证通过的容器内执行 `pip freeze` 生成 `requirements.lock`。

| 包 | 当前 | 建议锁定 |
|---|---|---|
| torch | >=2.0 | 待定 |
| openpyxl | >=3.1 | 待定 |
| matplotlib | >=3.7 | 待定 |
| python-docx | >=1.1 | 待定 |
| cityflow | 本地编译（`third_party/CityFlow`） | 固定 commit `81ee0f4` |

## 输出目录约定

| 路径 | 内容 |
|---|---|
| `outputs/metrics.csv` | 每次运行的汇总指标（append，不覆盖） |
| `outputs/trace_<algorithm>_<period>.json` | 车辆轨迹 |
| `outputs/live_*.jsonl` | 实时监控流 |
| `UGAT冻结主干_FARP部署与复现/logs/` | UGAT/FARP 训练与仿真指标（CSV/PNG/JSON） |
